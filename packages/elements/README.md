# @orange-ui/elements

37 framework-agnostic web components for Bitcoin and Lightning apps: checkout, pay button, amount and address inputs, QR, fee selector, transactions, wallet connect and recovery-phrase flows.

```html
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/@orange-ui/elements/dist/cdn/orange-ui.js"
></script>
<ou-pay-button amount="21000" adapter="mock"></ou-pay-button>
```
