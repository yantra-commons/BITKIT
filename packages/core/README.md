# @bitkit-ui/core

Headless Bitcoin + Lightning logic: exact bigint amounts, address validation (BIP-173/350), BIP21 and unified QR, BOLT11/BOLT12 decoding, LNURL, Lightning Address, fees and BIP39 helpers. No DOM.

```ts
import { parsePaymentInput, formatAmount, toMsat } from '@bitkit-ui/core';
```
