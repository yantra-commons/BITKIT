# Open decisions

Decisions only the maintainer can make. Each has a recommended default that is **already in
use**; change it and run the noted command.

| #   | Decision                    | Default in use                                                                                                                                             | Notes                                                                                                                                                                                                                                                                        |
| --- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Project name / npm scope    | `bitkit-ui`, `@bitkit-ui/*`                                                                                                                                | ⚠️ "Bitkit" is an existing Bitcoin wallet by Synonym — likely confusing and possibly a trademark issue. Alternatives: `satskit`, `orange-ui`, `btc-elements`, `bitcoin-ui-kit`. Rename: edit `kit.config.json` then `node scripts/rename.mjs`. Check npm availability first. |
| 2   | Custom element prefix       | `bk-`                                                                                                                                                      | Short and unlikely to collide. Changed with the rename script (`elementPrefix`).                                                                                                                                                                                             |
| 3   | Brand colors                | Bitcoin orange `#F7931A` accent, neutral grays; dark theme default follows `prefers-color-scheme`                                                          | All in `packages/tokens/src/tokens.json`. Accent text on white uses a darker orange (`#A65800`) to meet 4.5:1 contrast.                                                                                                                                                      |
| 4   | Adapter priority            | mock → BTCPay Server → LNbits → generic polling → NWC → OpenNode                                                                                           | BTCPay is the most common self-hosted merchant stack and open source; NWC ships with a pluggable client rather than bundled crypto.                                                                                                                                          |
| 5   | Default fee/rate source     | mempool.space (`https://mempool.space/api`), configurable base URL                                                                                         | Self-hostable, open source, no key. Fiat price default: mempool.space `/v1/prices`.                                                                                                                                                                                          |
| 6   | Default display unit        | `sats` (with `auto` available)                                                                                                                             | Bitcoin Design Guide recommends sats-first for small amounts.                                                                                                                                                                                                                |
| 7   | License                     | MIT                                                                                                                                                        | As requested.                                                                                                                                                                                                                                                                |
| 8   | Docs host                   | Cloudflare Workers (static assets) at `https://bitkit.dvsv2004.workers.dev/`                                                                               | `siteUrl`/`siteBase` in `kit.config.json`; Cloudflare builds on every push to `main` (build: `pnpm turbo run build --filter=@bitkit-ui/website...`, deploy: `wrangler deploy --assets=apps/website/dist`). GitHub Pages workflow kept as manual fallback.                    |
| 9   | GitHub owner / repo URL     | `yantra-commons/BITKIT`                                                                                                                                    | Replace in `kit.config.json` and re-run rename script.                                                                                                                                                                                                                       |
| 10  | Bitcoin Connect integration | Optional: if `<bc-button>` / `@getalby/bitcoin-connect` is on the page, `bk-wallet-connect` uses it; otherwise falls back to raw WebLN + NWC string input. | Avoids reinventing Alby's work; no hard dependency.                                                                                                                                                                                                                          |
