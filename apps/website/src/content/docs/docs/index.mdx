Bitkit UI is a set of accessible, themeable web components for the things every Bitcoin app needs:
amounts, addresses, invoices, payments, wallets and transactions.

- **Framework-agnostic.** Standard Web Components (Lit) that work in plain HTML, React, Vue,
  Svelte, Angular and Astro, with typed wrappers for React and Vue.
- **Correct by construction.** All Bitcoin logic lives in a headless, fully tested core:
  bigint money math, BIP-173/350 address validation, BIP21 and unified QR, BOLT11/BOLT12, LNURL.
- **Built on the [Bitcoin Design Guide](https://bitcoin.design).** Terminology, chunked
  addresses, unified QR, payment states and backup flows follow its patterns.
- **Non-custodial.** Components never request, store or transmit private keys. Recovery-phrase
  components are memory-only.
- **Provider-agnostic.** Payments go through a tiny adapter interface: mock, BTCPay Server,
  LNbits, OpenNode, Nostr Wallet Connect, or your own backend.
