title: Theming

All styling flows from design tokens: CSS custom properties prefixed `--bk-`. Components never
hard-code colors.

## Light and dark

Components follow the user's `prefers-color-scheme`. Force a theme on any ancestor, or on a
single component, with `data-bk-theme`:

```html
<html data-bk-theme="dark">
  <!-- or -->
  <bk-checkout data-bk-theme="light"></bk-checkout>
</html>
```

## Override tokens

Token defaults use zero-specificity `:where()` selectors, so a plain rule always wins, whatever
the load order:

```css
:root {
  --bk-color-accent: #7b3fe4;
  --bk-color-accent-hover: #6a2fd3;
  --bk-color-on-accent: #ffffff;
  --bk-radius-md: 4px;
  --bk-font-sans: 'Inter', system-ui, sans-serif;
}
[data-bk-theme='dark'] {
  --bk-color-accent: #a77bff;
}
```

Use the [theme builder](../../../theme-builder/) to design a theme with live contrast checks and
export exactly these lines.

### Token reference

| Group  | Examples                                                                                                                                                                                   |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Color  | `--bk-color-bg`, `surface`, `surface-2`, `text`, `text-muted`, `border`, `accent`, `on-accent`, `accent-text`, `success`, `warning`, `danger`, `info` (+ `-bg`), `focus`, `qr-fg`, `qr-bg` |
| Type   | `--bk-font-sans`, `--bk-font-mono`, `--bk-font-size-xs…2xl`, `--bk-font-weight-*`                                                                                                          |
| Space  | `--bk-space-1…10`                                                                                                                                                                          |
| Shape  | `--bk-radius-sm/md/lg/full`, `--bk-control-height-sm/md/lg`, `--bk-shadow-sm/md/lg`                                                                                                        |
| Motion | `--bk-duration-fast/normal/slow`, `--bk-easing-standard` (all zero under reduced motion)                                                                                                   |

The full list is in `@bitkit-ui/tokens/tokens.json`, and also exported as TypeScript:

```ts
import { cssVariables, defaults } from '@bitkit-ui/tokens';
```

Every text/background pair in the default themes is tested to meet WCAG 2.2 AA.

:::note[QR codes stay dark-on-light]
`--bk-color-qr-fg` and `--bk-color-qr-bg` default to black on white in both themes, because many
wallets fail to scan inverted codes.
:::

## Deep styling with parts

Each component documents its CSS parts. Target them from outside the shadow root:

```css
bk-checkout::part(base) {
  border-radius: 0;
  box-shadow: none;
}
bk-amount-display::part(unit) {
  text-transform: uppercase;
}
```
