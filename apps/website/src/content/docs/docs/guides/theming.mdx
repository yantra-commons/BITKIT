title: Theming

All styling flows from design tokens: CSS custom properties prefixed `--ou-`. Components never
hard-code colors.

## Light and dark

Components follow the user's `prefers-color-scheme`. Force a theme on any ancestor, or on a
single component, with `data-ou-theme`:

```html
<html data-ou-theme="dark">
  <!-- or -->
  <ou-checkout data-ou-theme="light"></ou-checkout>
</html>
```

## Override tokens

Token defaults use zero-specificity `:where()` selectors, so a plain rule always wins, whatever
the load order:

```css
:root {
  --ou-color-accent: #7b3fe4;
  --ou-color-accent-hover: #6a2fd3;
  --ou-color-on-accent: #ffffff;
  --ou-radius-md: 4px;
  --ou-font-sans: 'Inter', system-ui, sans-serif;
}
[data-ou-theme='dark'] {
  --ou-color-accent: #a77bff;
}
```

Use the [theme builder](../../../theme-builder/) to design a theme with live contrast checks and
export exactly these lines.

### Token reference

| Group  | Examples                                                                                                                                                                                   |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Color  | `--ou-color-bg`, `surface`, `surface-2`, `text`, `text-muted`, `border`, `accent`, `on-accent`, `accent-text`, `success`, `warning`, `danger`, `info` (+ `-bg`), `focus`, `qr-fg`, `qr-bg` |
| Type   | `--ou-font-sans`, `--ou-font-mono`, `--ou-font-size-xs…2xl`, `--ou-font-weight-*`                                                                                                          |
| Space  | `--ou-space-1…10`                                                                                                                                                                          |
| Shape  | `--ou-radius-sm/md/lg/full`, `--ou-control-height-sm/md/lg`, `--ou-shadow-sm/md/lg`                                                                                                        |
| Motion | `--ou-duration-fast/normal/slow`, `--ou-easing-standard` (all zero under reduced motion)                                                                                                   |

The full list is in `@orange-ui/tokens/tokens.json`, and also exported as TypeScript:

```ts
import { cssVariables, defaults } from '@orange-ui/tokens';
```

Every text/background pair in the default themes is tested to meet WCAG 2.2 AA.

:::note[QR codes stay dark-on-light]
`--ou-color-qr-fg` and `--ou-color-qr-bg` default to black on white in both themes, because many
wallets fail to scan inverted codes.
:::

## Deep styling with parts

Each component documents its CSS parts. Target them from outside the shadow root:

```css
ou-checkout::part(base) {
  border-radius: 0;
  box-shadow: none;
}
ou-amount-display::part(unit) {
  text-transform: uppercase;
}
```
