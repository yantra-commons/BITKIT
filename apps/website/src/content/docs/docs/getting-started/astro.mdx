---
title: Astro
description: Astro renders web components natively. Import once in a script.
---

Astro passes custom elements through untouched, so you use the raw tags in `.astro` files and
register them in a client `<script>`:

```astro title="src/pages/shop.astro"
---
const price = 21000;
---
<bk-amount-display amount={price} show-fiat fiat-currency="USD" fiat-price="97250"></bk-amount-display>
<bk-pay-button amount={price} adapter="store" description="Flat white"></bk-pay-button>

<script>
  import '@bitkit-ui/elements/pay-button';
  import '@bitkit-ui/elements/amount-display';
  import { registerAdapter } from '@bitkit-ui/elements';
  import { createHttpAdapter } from '@bitkit-ui/adapters/http';

  registerAdapter('store', createHttpAdapter({ baseUrl: '/api/payments' }));
</script>
```

This documentation site is built exactly this way. Every live example in it is a real component.

Object or array properties (such as `transactions` on `<bk-transaction-list>`) are set from the
script with `element.transactions = [...]`.
