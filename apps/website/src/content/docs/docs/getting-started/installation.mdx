Bitkit UI is split into small packages. Install only what you need:

| Package                               | What it is                                                                      |
| ------------------------------------- | ------------------------------------------------------------------------------- |
| `@bitkit-ui/elements`                 | The web components (`<bk-checkout>`, `<bk-amount-input>`…).                     |
| `@bitkit-ui/adapters`                 | Payment providers (mock, BTCPay, LNbits, OpenNode, NWC, HTTP) and rate sources. |
| `@bitkit-ui/core`                     | Headless logic: units, addresses, BIP21, BOLT11, LNURL, fees. No DOM.           |
| `@bitkit-ui/tokens`                   | Design tokens as CSS variables and JSON.                                        |
| `@bitkit-ui/react` / `@bitkit-ui/vue` | Typed wrappers for React 18+ and Vue 3.                                         |

## Register components

Importing a component registers its custom element. Import everything, or only what you use
for smaller bundles:

```ts
// Everything
import '@bitkit-ui/elements';

// Or just what you need
import '@bitkit-ui/elements/checkout';
import '@bitkit-ui/elements/amount-input';
```

Design tokens are injected automatically the first time a component connects. To ship them
yourself (for example with a strict Content Security Policy), import the stylesheet and turn
injection off:

```ts
import '@bitkit-ui/tokens/tokens.css';
import { configure } from '@bitkit-ui/elements';
configure({ injectTokens: false });
```

## Global defaults

```ts
import { configure } from '@bitkit-ui/elements';

configure({
  network: 'mainnet', // what address inputs expect and badges show
  unit: 'sats', // default amount unit: sats | btc | fiat | auto
  locale: 'en-IN', // number formatting (lakh grouping in this case)
  fiatRate: { currency: 'USD', price: '97250' },
});
```

Mounted components re-render when you call `configure` again.

## Requirements

- Any evergreen browser (Chrome, Edge, Firefox, Safari 15.4+).
- Node 22+ for server-side rendering frameworks. Components are SSR-safe: importing them on the
  server does nothing until they reach a browser.
