---
title: Contributing
description: How to develop, test and propose changes.
---

```sh
git clone https://github.com/your-org/bitkit-ui && cd bitkit-ui
pnpm install
pnpm build && pnpm test          # everything green before you start
pnpm storybook                   # develop components
pnpm --filter @bitkit-ui/website dev   # docs site
```

- Conventions are in [`CLAUDE.md`](https://github.com/your-org/bitkit-ui/blob/main/CLAUDE.md) and
  [`CONTRIBUTING.md`](https://github.com/your-org/bitkit-ui/blob/main/CONTRIBUTING.md).
- Good first issues are listed in
  [`docs/ROADMAP.md`](https://github.com/your-org/bitkit-ui/blob/main/docs/ROADMAP.md).
- Every component needs a story, unit and axe tests, a docs example, and light/dark support.
- Add a changeset (`pnpm changeset`) to any PR that changes a published package.
