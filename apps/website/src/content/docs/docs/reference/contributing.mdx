---
title: Contributing
description: How to develop, test and propose changes.
---

```sh
git clone https://github.com/yantra-commons/BITKIT && cd orange-ui
pnpm install
pnpm build && pnpm test          # everything green before you start
pnpm storybook                   # develop components
pnpm --filter @orange-ui/website dev   # docs site
```

- Conventions are in [`CLAUDE.md`](https://github.com/yantra-commons/BITKIT/blob/main/CLAUDE.md) and
  [`CONTRIBUTING.md`](https://github.com/yantra-commons/BITKIT/blob/main/CONTRIBUTING.md).
- Good first issues are listed in
  [`docs/ROADMAP.md`](https://github.com/yantra-commons/BITKIT/blob/main/docs/ROADMAP.md).
- Every component needs a story, unit and axe tests, a docs example, and light/dark support.
- Add a changeset (`pnpm changeset`) to any PR that changes a published package.
